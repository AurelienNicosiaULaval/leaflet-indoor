# Contributing

Reproducible bug reports and focused pull requests are welcome.

1. Search the issue tracker before opening a new issue.
2. Include a minimal `sf` or GeoJSON example that does not contain sensitive
   building information.
3. Run `devtools::test()` and `devtools::check()` before submitting code.
4. Add tests for behavior changes and update the relevant documentation.

Please do not include credentials, private floor plans, or personally
identifiable location data in issues or test fixtures.
