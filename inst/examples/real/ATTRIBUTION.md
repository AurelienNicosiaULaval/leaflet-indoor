# Louvre example data and media

The room geometries in `louvre-rooms.geojson` are a selected extract from
OpenStreetMap at the Louvre Museum in Paris, downloaded on 2026-09-08. The
example contains 135 community-mapped, named indoor rooms or areas on levels
`-2`, `0`, and `1`. Each feature retains its OpenStreetMap way identifier,
version, and source URL. The compressed API response used to derive the
GeoJSON is retained as `data-raw/louvre-osm-2026-09-08.osm.gz`.

OpenStreetMap data is available under the Open Data Commons Open Database
License (ODbL) 1.0. Copyright belongs to OpenStreetMap contributors. The
geometry extract was limited to named indoor rooms and areas, ordered by floor
and room name, and serialized as GeoJSON.

- Source: <https://www.openstreetmap.org/copyright>
- Snapshot API request: <https://api.openstreetmap.org/api/0.6/map?bbox=2.335,48.859,2.340,48.8612>
- License: <https://opendatacommons.org/licenses/odbl/1-0/>

The bundled photographs show the Salle des Caryatides at the Louvre. They are
stored at 1280-pixel resolution without visual modification.
